# Build brief — "The Journeyman's File" (rea-miaai-hub prompt-formula)

A framed journeyman's workbench-folio seen straight on: four numbered artifacts from one career hung along one continuous journey line, lit from a warm drafting-table day into a departure-board night.
Concept: one career, one spine — every act is a physical artifact from a different bench, the spine carries the eye sheet to sheet, and the page darkens exactly once (dusk bridge → finale).
Lore: The Journeyman's File · QVN-2026 · four sheets, est. 2014; sheets numbered 0–4, each colophon stamping the next sheet's kicker.
Palette (per sheet, hex with jobs): S0 cover — draft paper `#F4F1E8`, drafting ink `#1B4F9C`, pencil `#FFD23F`. S1 Papers — same draft set, ink carries all rules/text, pencil only the GPA highlight + Received stamp. S2 Workshop — linen `#EFE7D6` with 3-gradient weave + multiply grain, iron ink `#2A2A2A`, madder `#A8452C` (years/active thread), weld `#D9A441` (hover only). S3 Platform — grid paper `#F6F1EA`, card `#FDFBF7`, navy ink `#2B2D42`, energy `#FFD166` (offset shadows + live meters). S4 Horizon (dark) — board `#060605`, cream ink `#F2EFE4`, signal `#F5C400` (status/lamps/focus), alarm `#D4401F` reserved. Light page throughout except S4.
Texture: drafting-sheet double borders + faint zone grid; linen weave gradients + grain ≤.09 opacity; paper cards with hard energy offset shadows; flap cells with inset top-light + hairline split; feTurbulence grain veil on light sheets.
Interaction: S1 draw-on ledger (`pathLength=1`) + stamp slam on scroll; S2 damped-cosine beat recoil ≤2.4px + glossary tooltips; S3 optional isometric town (≤12 buildings), dash speed ∝ load; S4 flap title "WHERE NEXT" clatters once on load (9ms/char · 58ms/row · pow(p,1.7) fold), opt-in clatter sound (lazy AudioContext, default off); keyboard operable throughout, focus rings in each act's accent.
Reduced motion: CSS + JS matchMedia contract; entrances off, transitions .01ms; flow dashes → static arrowheads; precomputed end states.
Implementation: one self-contained `index.html`, inline CSS+JS, zero deps, zero webfonts, 30–110KB; Georgia/Garamond + Gill Sans + Arial Narrow + Menlo stacks; SVG for drafting/town, DOM for text; DPR ≤2, idle rAF stop, visibilitychange pause. All facts from `fact-sheet.md`; all words from `draft-copy.md`; full rules in `style.md`.
