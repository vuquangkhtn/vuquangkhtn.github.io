# Portfolio regeneration

The shared language for regenerating this portfolio in the Claude Fable design language as a fusion of four storytelling styles.

## Language

**Act**:
One of the four chapters of the portfolio (papers, workshop, platform, horizon); each act is owned by exactly one style-unit.
_Avoid_: section, stop, stage

**Style-unit**:
The fusion of one donor study's visual language with one narrative voice; the unit the site's style system is built from, documented in style.md.
_Avoid_: style, theme, skin

**Donor study**:
A Claude Fable catalog study whose visual language a style-unit borrows.
_Avoid_: reference study, template, source file

**Narrative voice**:
The storytelling register — genre, person, tense, metaphor — a style-unit writes its copy in.
_Avoid_: tone, persona, mood

**Overture**:
The page's opening hero; introduces the traveler before the acts begin.
_Avoid_: hero section, landing, splash
