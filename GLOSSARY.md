# Portfolio regeneration

The shared language for regenerating this portfolio in the Claude Fable design language as a fusion of four storytelling styles.

## Language

**Era**:
One of the nine thematic slides staging the portfolio story in a computing-era aesthetic; eras are staging for the portfolio, never a history lesson — no history years are shown.
_Avoid_: act, section, chapter, page

**Style-unit**:
The fusion of one donor study's visual language with one era slide's aesthetic; the unit the deck's style system is built from, documented in style.md.
_Avoid_: style, theme, skin

**Donor study**:
A Claude Fable catalog study whose visual language an era borrows.
_Avoid_: reference study, template, source file

**Narrator line**:
The single continuous first-person voice carrying the story across all eras.
_Avoid_: tone, persona, copy

**Artifact text**:
Period-register text inside an era's props — labels, captions, fake documents; the layer where each era speaks its own language.
_Avoid_: narration, body copy

**Timeline rail**:
The bottom navigation strip naming the eras (no years); current era highlighted, every tick jumpable.
_Avoid_: progress bar, nav, spine

**Era transition**:
The era-appropriate choreographed hand-off between two adjacent slides (card feed, CRT power-on, flap flip).
_Avoid_: page change, scroll animation

**Cover**:
Slide zero — the folio cover that names the engineer and opens the story.
_Avoid_: hero, splash, overture
